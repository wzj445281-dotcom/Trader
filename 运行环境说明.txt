1. 环境依赖 (Prerequisites)

在运行本项目前，请确保您的本地环境满足以下要求：

操作系统: Windows 10/11, macOS, 或 Linux

Java 环境: JDK 17 或以上版本

Node.js 环境: Node.js 16.0 或以上 (含 npm)

数据库: MySQL 8.0+

容器化工具: Docker Desktop (可选，如果使用 Docker 部署)

开发工具: IntelliJ IDEA (推荐用于后端), VS Code (推荐用于前端)

2. 数据库初始化 (Database Setup)

找到压缩包根目录下的 sql 文件夹（或 backend 根目录下的 sql_init.sql / full_structure.sql）。

在您的 MySQL 数据库中执行该 SQL 脚本。它会自动创建名为 trader 的数据库，并导入初始表结构和测试数据。

注意: 默认配置的数据库用户名为 root，密码为 000000。如果您的数据库密码不同，请在后端配置中修改。

3. 后端启动 (Backend Setup)

使用 IntelliJ IDEA 打开 backend 文件夹。

打开 src/main/resources/application.yml 文件。

修改数据库配置:

spring:
  datasource:
    url: jdbc:mysql://localhost:3306/trader...
    username: root      # 修改为您的数据库用户名
    password: "您的密码" # 修改为您的数据库密码



等待 Maven 依赖下载完成。

找到 src/main/java/com/trader/app/App.java (启动类)，右键点击 "Run 'App'"。

当控制台看到 Started App in ... seconds 时，后端启动成功，运行在端口 8080。

4. 前端启动 (Frontend Setup)

在 frontend 目录下打开终端 (Terminal) 或命令提示符 (CMD)。

安装依赖 (初次运行需要，耗时较长):

npm install



(建议使用淘宝镜像: npm install --registry=https://registry.npmmirror.com)

启动开发服务器:

npm run dev



当终端显示 Local: http://localhost:5173/ 时，前端启动成功。

打开浏览器访问 http://localhost:5173 即可进入系统。

6. 常见问题 (Troubleshooting)

图片无法显示:

请确保后端已成功启动。项目默认将上传的图片保存在 backend/uploads 目录下。如果是第一次运行，请手动在 backend 目录下创建一个名为 uploads 的空文件夹。

登录提示 "Network Error":

请检查后端端口是否为 8080。如果端口被占用，请在 application.yml 中修改端口，并同步修改前端 vite.config.js 中的代理配置。
